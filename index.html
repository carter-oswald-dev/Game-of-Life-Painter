    How it works
    
Text: every character has starting patterns, found ahead of time with a SAT solver, that grow into its 5×7 letter. Each one sits in its own box with a 1-cell border that stays dead in every generation, so neighbouring letters can't influence each other.
    With "Blink forever" on, every letter pixel is a blinker (a 3-cell oscillator), so the text keeps flipping between horizontal and vertical dashes forever.
    Supported: A–Z (lowercase shows as uppercase), 0–9, space and . Anything else becomes "?". Text is available at 2 generations.

    
Image: every picture pixel is a tile. There are only two kinds, filled and empty, each with 32 different seeds picked at random, so the noise has no repeating texture.
    Without blinking, an 8×8 tile becomes a solid 5×5 square or dies out. With "Blink forever" on, a 10×10 tile becomes four blinkers or dies out, and the blinkers flip forever.
    Filled and empty seeds have the same number of live cells, with the same amount near the centre, so you can't see the picture in the noise.

    
Neighbouring tiles share a 1-cell dead gutter. Every seed keeps its corner cells dead, and in every generation each gutter cell touches at most one of its live cells.
    Two tiles together can therefore give a gutter cell at most 2 neighbours, which is never enough for a birth (that needs exactly 3), so tiles can't affect each other.
    Without blinking, that guarantee ends at the reveal and the picture breaks up afterwards. The blinkers obey the same rule in both of their phases, so a blinking picture never breaks up.

    
Dithering: the eleven error-diffusion kernels and Bayer come from Threshold It Not.
    "Let trained model choose" scores all 23 options (11 kernels with serpentine off or on, plus Bayer) with your trained ranker, which looks at the photo, and uses the top one.
    "Smallest RLE file" dithers the picture every possible way, builds each seed with the same random tile picks, and keeps the one whose RLE file is smallest.
    Every pixel turns into noise whether it's filled or empty, so the dithering choice only changes file size by a few percent. Width is what really sets the size.
    After every scramble the page re-runs the seed itself and checks it cell for cell.
