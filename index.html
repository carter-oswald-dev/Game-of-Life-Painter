    How it works
    
Every character has precomputed starting patterns (found with a SAT solver) that evolve into its 5×7 letter.
    In blinker mode every letter pixel is a blinker (a 3-cell oscillator), so the text flips between horizontal and vertical dashes forever instead of dissolving.
    Each pattern sits in its own box with a 1-cell border that is forced to stay dead in every generation, so neighbouring
    letters can never influence each other. The page re-runs the result itself after every scramble and checks it cell for cell.
    Supported: A–Z (lowercase shows as uppercase), 0–9, space and . Anything else becomes "?".
    After the reveal, the text keeps evolving like any other pattern.
